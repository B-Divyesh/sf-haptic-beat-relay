# Demo sandbox

- URL: `http://localhost:8080/?demo=1` locally or `https://haptic-beat-relay.sociobot.in/?demo=1` when deployed. `/demo` also opens the same isolated sample.
- Sample: a paired host room named `DEMO24`, friend Sam, 104 BPM cues, two past scores, and a 12-second sample round.
- Start: choose **Try it with sample data** on the first screen. The used product opens in one click.
- Reset: choose **Reset demo** in the persistent banner.
- Leave: choose **Create a real room**. Demo state is discarded.
- Storage namespace: none. Demo state lives only in page memory and never reaches the room backend or browser storage.
