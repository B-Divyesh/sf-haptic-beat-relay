# Demo sandbox

- URL: `http://localhost:8080/demo` locally or `https://haptic-beat-relay.sociobot.in/demo` when deployed.
- Sample: a paired host room named `DEMO24`, companion Sam, a 104 BPM night-practice click, two past scores, and a 12-second sample round.
- Start: choose **Try it with sample data** on the first screen. The used product opens in one click.
- Reset: choose **Reset demo** in the persistent banner.
- Leave: choose **Start for real**. Demo state is discarded.
- Storage namespace: none. Demo state lives only in page memory and never reaches the room backend or browser storage.
